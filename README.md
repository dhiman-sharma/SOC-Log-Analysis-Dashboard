# 🛡️ SOC Log Analysis & Incident Investigation Dashboard

A Security Operations Center (SOC) dashboard built using Python and Streamlit for analyzing authentication logs and investigating security incidents.

# Features
- Authentication Log Monitoring
- Failed Login Detection
- Suspicious Activity Detection
- Brute Force Detection
- Security Analytics
- Incident Report Generation
- Interactive Visualizations

# Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- Matplotlib
- Seaborn
